## Featured Projects

### Credit Risk Prediction — Stacking Ensemble ML System

An end-to-end machine learning system for predicting serious loan delinquency across **150,000 borrowers**.

- Engineered 11 predictive features and applied VIF-based feature selection
- Developed XGBoost, LightGBM, and CatBoost models
- Optimized models using Optuna
- Built a stacking ensemble with Logistic Regression as the meta-learner
- Applied SMOTE exclusively within cross-validation folds to prevent data leakage
- Achieved **0.8588 ROC-AUC** and **0.3558 PR-AUC**
- Used SHAP and Partial Dependence Plots for model interpretability

**Technologies:** Python, Scikit-learn, XGBoost, LightGBM, CatBoost, Optuna, SHAP, Pandas, NumPy

[View Project](https://github.com/Joo-Sebaii)
